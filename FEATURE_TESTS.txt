안정성 수정판 1 — 검증 범위

실제 Chromium / js-dos 6.22 실행
- 교정판: 돈 1,000,000 추가 → 빠른 이동 → 여관 진입 → 숙박.
- 1522년 5월 17일 13:20부터 5월 21일 08:00까지 4회 연속 숙박.
- 매번 마을 화면 복귀와 키 입력 반응 확인.
- 원작판도 동일한 돈 추가/빠른 이동 후 숙박 1회, 다음 날 08:00 복귀 확인.
- 교정판·원작판: 서로 다른 선박 인스턴스 3척을 가진 테스트 상태에서 A/S 실행.
- A: 각 배 물/식량/포탄 100/100/50 → 245/245/50.
- S: 각 배 100/100/50 → 240/240/60.
- S 3척 구매 후 금화 환산 1,000,000 → 988,480.
- 보급 후 ESC로 화면 전환 확인.

16비트 명령어 실행 검증 (게임 UI와 별도)
- 원작판·교정판의 실제 패치 명령어를 x86 에뮬레이터에서 실행.
- 서로 다른 용량의 배 0/1/2/3/10척 A/S 처리, 적재 한도와 비용 검증.
- 소지금 0인 3척 상태에서 무료 물품 증가 없음.
- 빠른 이동 선택/취소/요청 없음: 호출자 복귀 주소와 BX/CX/DX/SI/DI 보존.
- DOS 로더 재배치 적용 후 시작 코드 실행: 추가 영역 예약, 원래 DS/스택 유지.
- 원래 작업 메모리를 덮어쓰는 시험에서 이동한 코드가 손상되지 않음.

무결성
- 배포본의 모든 원본 게임 ZIP 및 기본 세이브 데이터는 이전판과 바이트 단위 동일.
- 이전 사용자 저장 파일을 배포용 기본 세이브로 넣지 않음.
- 실게임 검증에 사용한 3척 상태는 테스트 전용 메모리 구성.
- 모든 게임 상황과 장기간 플레이를 전수 검증한 것은 아님.
