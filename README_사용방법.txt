대항해시대2 로컬 웹 — 편의 기능 안정성 수정판 1
화면 상단 표시: STABILITY FIX 1

이번 수정
- 빠른 이동이 복귀 주소와 공통 키 입력 처리를 바꾸던 방식을 제거했습니다.
- 빠른 이동은 현재 마을 프레임으로 정상 복귀하며, 취소도 같은 경로를 사용합니다.
- A/S 보급·건조 단축·빠른 이동 코드를 원래 작업 메모리/스택과 분리했습니다.
- 시작 시 추가 코드 공간을 DOS에 별도로 예약하고, C 런타임의 기존 힙/스택 범위는 유지합니다.
- 저장 파일 형식과 게임별 브라우저 저장 공간 이름은 유지합니다.

실행
1. 이전 게임에서 저장하고 세이브 내려받기로 백업합니다.
2. 이전 PowerShell 창을 닫습니다.
3. ZIP 전체를 새 폴더에 풀고 START.cmd를 실행합니다.
4. 교정판 자동보급 실행 또는 원작 자동보급 실행을 선택합니다.
같은 브라우저와 주소·포트·게임 버전을 사용하면 기존 브라우저 세이브를 사용할 수 있습니다.
게임 중에는 PowerShell 창을 최소화해 두고 닫지 않습니다.

편의 설정
게임 아래 '편의 설정'을 누릅니다.
건조 기간: 원래대로 / 25% / 50% / 75% / 100% 단축.
단축 설정은 이후 새로 주문하는 선박에 반영됩니다. 소수점은 버립니다.
빠른 이동: 체크한 뒤 마을에서 Numpad 5 또는 '빠른 이동' 버튼을 누릅니다.
현재 마을에 실제 있는 시설 목록에서 목적지를 선택합니다. 건물 안에서는 먼저 밖으로 나옵니다.
돈 추가: '+ 1,000,000' 버튼을 누를 때마다 금화 환산 1,000,000 추가.
게임에서는 금괴 100개로 보일 수 있습니다. 버튼의 상한은 금화 환산 99,999,999입니다.
추가한 돈을 보관하려면 반드시 게임 안에서 저장합니다. 화면의 소지금 숫자는 다음 화면 전환 때 갱신될 수 있습니다.
설정은 브라우저가 기억합니다. 처음에는 건조 단축과 빠른 이동이 꺼져 있습니다.
편의 설정은 원작 자동보급판과 교정판 자동보급판에서 지원합니다.

자동보급
항구 → 보급 화면에서 A 또는 'A 자동보급' 버튼.
식량 구매비가 필요합니다. 돈이 없고 물·식량이 이미 균등하다면 변화가 없을 수 있습니다.
여러 배의 적재 여유와 현재 보급량을 계산하고 물·식량을 균등하게 보충합니다.
S 또는 'S 포탄+보급' 버튼: 각 배에 포탄을 최대 10개 먼저 추가하고, 남은 공간에 물·식량을 균등보급합니다.
이미 포탄이 있으면 현재 수량에서 최대 10개를 더 싣습니다. 10개로 고정하는 기능이 아닙니다.
포탄과 식량 비용은 정상 차감하며, 적재 공간과 소지금 범위를 넘기지 않습니다.
이미 배가 가득 찼다면 포탄을 추가할 수 없습니다. 필요한 만큼 물·식량을 내린 후 사용합니다.
A는 기존처럼 물·식량만 보급합니다.

화면
GitHub 원본과 같은 4:3 최대 확대 및 브라우저의 부드러운 보간을 사용합니다.
키패드와 아래 버튼은 화면 위에 겹쳐지며 게임 크기를 줄이지 않습니다.
'버튼 숨기기'를 누르면 작은 '조작' 버튼만 남습니다.
전체 화면 해제: Esc.

저장
숙박과 보급은 자동 저장이 아닙니다. 게임 내부에서 먼저 저장합니다. '브라우저 저장 완료' 표시를 확인합니다.
'세이브 내려받기'로 PC에 백업할 수 있습니다.
게임 파일과 업로드한 세이브를 배포본의 기본 세이브로 교체하지 않았습니다.
