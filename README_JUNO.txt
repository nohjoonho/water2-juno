대항해시대2 · Edit by Juno / 2026-11-07

실행: 이 폴더의 START.cmd 또는 시작.bat
주소: http://127.0.0.1:8785/ (사용 중이면 8786~8795)
기존 UW2_Convenience_Stability_Fix1 폴더는 수정하지 않았습니다.
기존판과 포트·브라우저 설정 키·저장 공간을 분리했습니다.
이전 세이브: 이전판에서 게임 안에 저장 → 세이브 내려받기 →
새 버전의 같은 게임에서 세이브 불러오기 → 새로고침 후 같은 게임 실행.

적용 범위
- 위쪽 교정판/원작: 자동보급 및 게임 편의 기능.
- 아래쪽 오리지널/모드: 실행 파일 패치 없음. 편의 설정의 음량 조절 가능.

패치
- A: 항구 보급 화면에서 물·식량 균등 보급.
- S: 배마다 포탄을 10개로 맞춘 뒤 물·식량 보급.
  10개 미만은 부족분만 구매, 10개 초과는 초과분을 내립니다(환불 없음).
  공간이 부족하면 물부터, 그다음 식량을 조정해 포탄 자리를 확보합니다.
  자금 또는 다른 적재물 때문에 공간이 부족하면 가능한 수량까지만 보급합니다.
  다른 적재물은 내리지 않습니다. A는 기존 물·식량 보급 동작을 유지합니다.
- 금화 1,000,000 추가 / 건조 기간 단축 / 항내 빠른 이동.
- 희귀 장비 확률 제거: 카로네이드·천사/여신 선수상. 항구/인물 조건 유지.
- 해상 이벤트 제거: 체크하면 제거, 해제하면 원래 판정으로 복원.
  신규 폭풍·무풍·안개, 쥐·전염병 처리 및 특수 해상 이벤트 차단.
  기존 날씨의 자연 종료, 스토리, 발견, 함대 조우는 유지.
- 물·식량 소비 고정: 정상 소비 및 쥐의 식량 차감 차단.
- 강운: 체크 중 주인공 행운 100 유지.
- 현재 항구 상업·공업 1000: 체크 중 방문한 항구의 발전도 두 값을 1000으로 설정.
  투자 대기액을 넣는 것이 아니라 발전도를 즉시 1000으로 만듭니다.
- 미고용 이름 강조: 항구에서 항해사 이름을 밝은 파란색으로 표시.
  주인공 및 고용 목록의 인물은 원래 색상 유지. 설정에서 끌 수 있습니다.
- 음악/효과음 통합 음량: 편의 설정에서 0~100%. 0% 음소거.

체크박스는 체크 시 편의 기능 적용, 해제 시 해당 기능 해제입니다.
행운·항구 발전도는 이미 변경한 수치를 해제할 때 되돌리지 않습니다.
금화·행운·발전도 변경을 보관하려면 게임 안에서 저장하세요.
건조 기간은 새 주문부터, 목록/수치 표시는 다음 화면 전환부터 반영될 수 있습니다.
물·식량이 처음부터 0이면 소비 고정만으로 자동 보충되지 않습니다.

검증
- 2026-11-07 S 수정: 양쪽 버전 실제 실행 파일의 S 분기부터 A 보급까지
  170개 16비트 실행 사례 통과. 반복 S 수량/비용 유지, 0/1/3/10척,
  포탄 0~100, 물·식량 만재, 자금 부족, 다른 화물 만재, A 회귀 포함.
- 원작/교정판 각각 16개 코드 옵션 조합 및 실행 중 전환/복원 통과.
- 행운/항구 데이터 변경, 해제, 타이틀/해상 상태 보호 확인.
- 16비트 실행: 소비/특수 이벤트 분기 112건, 이름 색상·고용 제외·레지스터/스택 48건 통과.
- Chromium 실제 교정판 새 게임 실행, 행운100/리스본 상업·공업1000 및 화면 표시 확인.
- 실제 DOSBox 오디오 출력 게인 35%=0.35 확인.
- 주점·여관의 모든 이름 표시 경로와 장기 항해는 전수 검증하지 않았습니다.
- 모든 원본 게임 ZIP은 기존 안정판과 SHA-256 동일.
