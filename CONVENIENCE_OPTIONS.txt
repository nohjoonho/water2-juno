2026-11-03 추가 편의 설정

지원: 원작 자동보급판 / 교정판 v1.08 자동보급판.
브라우저를 새로고침한 다음 편의 설정에서 사용합니다.
기본값: 희귀 장비 확률 제거 끔 / 해상 이벤트 사용 켬 / 물·식량 소비 고정 끔.
설정은 브라우저에 기억되며 게임 실행 파일 원본 ZIP은 수정하지 않습니다.

희귀 장비 확률 제거
- 선수상 선택 수를 늘리는 확률 분기 2곳, 대포 선택 수를 늘리는 확률 분기 1곳 제거.
- 항구 발전도와 조선공 능력 조건, 가격, 구매 과정은 유지.
- 조선소의 해당 메뉴에 다시 진입해야 선택 목록에 반영.

해상 이벤트 사용
- 체크 해제 시 폭풍/무풍/안개의 신규 발생 판정 호출 차단.
- 일일 쥐/전염병 처리 호출 차단. 기존 질병 플래그를 강제로 지우지는 않음.
- 이미 발생한 날씨의 종료 처리는 유지. 스토리, 발견, 함대 조우는 유지.

물·식량 소비 고정
- 일일 물/식량 차감 명령 2곳과 쥐에 의한 식량 차감 명령 1곳 차단.
- 현재 양을 기준으로 소비를 막으며 보급/매매/수동 적재량 변경은 허용.
- 처음부터 물이나 식량이 0이면 자동으로 채워주지는 않음.

검증
- 두 버전 각각 8개 옵션 조합으로 prepare 성공 (16개).

- Unicorn 16비트 실행: 소비 차단/정상 소비, 희귀 장비 분기 동작 144개 사례 통과.
