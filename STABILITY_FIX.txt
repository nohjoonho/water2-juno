편의 기능 안정성 수정판 1

수정 내용
1. 빠른 이동의 전역 BIOS 입력 변경 및 다른 메뉴/복귀 주소 변경을 제거.
   마을의 기존 입력 함수 한 곳에서 정상적인 호출/복귀로 처리하도록 변경.
2. 추가 코드를 원래 작업 힙/스택과 분리하고, 프로그램 시작 때 DOS 메모리로 예약.
3. A/S 보급, 금화 추가, 건조 기간 단축, 최대 화면 구성은 유지.

설치
- 기존 게임에서 저장할 수 있다면 저장 후 세이브 내려받기로 백업.
- 기존 PowerShell 서버 창을 종료.
- 이 ZIP을 새 폴더에 전부 풀고 START.cmd 또는 시작.bat 실행.
- 게임 선택 화면 상단 STABILITY FIX 1 확인.
- 이전에 쓰던 것과 같은 브라우저/주소/포트/게임 모드를 선택.

숙박과 보급은 자동 저장이 아닙니다. 게임 안에서 먼저 저장해 주세요.
이미 멈춰서 저장하지 못한 진행을 복구하는 파일은 아닙니다.
